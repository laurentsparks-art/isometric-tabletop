# Contributing and reporting issues

No public issue tracker is configured until the owner authorizes a public repository. Please report ODM version/commit and host patches, addon version, OS, browser/WebGL renderer, reproduction steps, expected/actual behavior and a redacted screenshot/console excerpt.

Never include passwords, cookies, QA databases, encryption keys or private campaign exports. Use a synthetic campaign. Keep artwork changes separate from bridge/build fixes and preserve the approved source hashes. ODM owns all game rules; do not add direct authenticated API calls inside the iframe. Run npm test, npm run release:audit and relevant Godot/browser tests before proposing changes.
