# Isometric Tabletop 0.1.0 — draft release notes

An optional pixel-art isometric board view for Open Dungeon Master: 27 environments, four-way rotation, miniature-style tokens, fog-aware terrain and the familiar ODM gameplay controls. ODM remains authoritative for rules, permissions and multiplayer state.

The package includes Godot's Web runtime. Administrators do not need Godot or another service. Install the addon folder through the official Addons interface, enable it and select Isometric on a campaign map.

**Unpublished release candidate.** Requires ODM 0.28.0 plus the host changes in framework-patches.md; do not advertise compatibility with unmodified ODM yet. Windows Chrome verified; desktop/Linux/macOS/mobile remain unverified. Board remains the fallback for measuring, advanced aiming and private pictures.

Code MIT, original artwork CC0 where rights are held, Godot/font notices retained. No permissions, telemetry or runtime downloads.

## Catalogue description

A rotatable isometric tabletop with 27 pixel-art environments, standees and player-safe fog. Draws existing ODM maps and sends selections back to ODM's authoritative gameplay controls.

## Announcement draft

Isometric Tabletop is our first optional Godot board-view addon for ODM. It keeps ODM's maps, rules and multiplayer authority while adding a rotatable pixel-art tabletop with 27 environments.
