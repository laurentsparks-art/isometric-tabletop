# Runtime screenshot provenance

These four PNGs are actual headed-Chrome captures of ODM 0.28.0 plus the installed Isometric Tabletop addon, using an isolated synthetic QA campaign. No passwords, session state or private campaign data are shown. primary/gameplay are real application views; environments/rotation are labelled contact sheets of real captures.

The original isometric artwork remains under its recorded CC0 dedication. Screenshots also show ODM's own interface and portrait assets; that dedication does not relicense the host's content. ODM application attribution and MIT notices remain in the repository LICENSE; fonts retain OFL terms. No host portrait source files are extracted or bundled into the addon runtime.

Full captures stay under ignored artifacts/release-browser and artifacts/gameplay. scripts/prepare-showcase.mjs assembles the documentation images; scripts/capture-gameplay.mjs uses the normal authenticated host interface to capture the enlarged battle view.
